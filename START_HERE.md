## 🆘 QUICK HELP

### "Nothing shows up"

```bash
# Make sure you're in right directory
cd "f:\Realm theroy"
# Make sure packages installed
pip install streamlit matplotlib plotly numpy scipy
# Try running again
streamlit run realm_simulator_enhanced.py
```

### "Animation doesn't work"

- Make sure slider value > 0
- Click "▶️ Start Animation" button (not just look at it)
- Wait for animation to complete
- Try refreshing page (F5)

### "Looks ugly/wrong"

- Try full screen (F11)
- Try different browser
- Refresh page (F5)
- Clear cache (press 'c')

### "Can't install streamlit"

```bash
# Update pip first
python -m pip install --upgrade pip
# Try again
pip install streamlit
```
