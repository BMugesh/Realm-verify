## 🆘 COMMON ISSUES & SOLUTIONS

### Issue 1: "ModuleNotFoundError: No module named 'streamlit'"

**Solution:**

```bash
pip install streamlit
```

### Issue 2: App runs but no visualizations appear

**Solution:**

```bash
# Make sure you're in correct directory
cd "f:\Realm theroy"
# Reinstall matplotlib and plotly
pip install matplotlib plotly --upgrade
```

### Issue 3: Animation doesn't play

**Solution:**

- Click "▶️ Start Animation" button
- Make sure slider value > 1
- Clear cache: Press 'c'
- Refresh page: Press F5

### Issue 4: Slow performance

**Solution:**

- Reduce path resolution to 100
- Use fewer animation frames
- Close other applications
- Restart Streamlit

### Issue 5: Port already in use

**Solution:**

```bash
# Use different port
streamlit run realm_simulator_enhanced.py --server.port 8502
```
